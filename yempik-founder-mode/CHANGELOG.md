# Changelog

## 1.0.0 (2026-07-30)

Initial release: five-stage pipeline (readiness gate, consensus map, divergence,
Brain grounding, thesis output), four frameworks (Thiel contrarian question,
inversion, schlep blindness, what-won't-change), propose-only changeset outlet.

## 1.0.1 (2026-07-30)

Grounding: the rule about verifying a returned decision stays, its rationale no longer
describes a server that answered off-topic queries by rank. `brain_get_current_decision`
now declines below a relevance bar, so the reference states what the note on a returned
decision means and that a declined lookup is a normal answer.
